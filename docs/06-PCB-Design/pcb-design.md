# PCB Design

## EGR 304 – Microphone Subsystem

**Joseph White – Team 203**

This page documents the printed circuit board (PCB) design for the microphone subsystem developed as part of the EGR 304 Embedded Systems team project.

The PCB was designed using KiCad and consists of two copper layers. The design includes the electronic components, connections, and supporting circuitry required for the microphone subsystem.

## PCB Layout

The following images show the top and bottom copper layers of the completed PCB design.

### Top Copper Layer

![Top PCB Layout](EGR304_JW_PCB_Top.png)

### Bottom Copper Layer

![Bottom PCB Layout](EGR304_JW_PCB_Bottom.png)

The bottom copper layer contains additional routed connections and a ground copper plane.
